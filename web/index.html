Cơ chế phân quyền

Every staff endpoint checks the session server-side before doing any work. Hiding a screen in JavaScript is not a control - the routes answer anyone who calls them directly, so the check lives in the handler.

Demo-grade: the account is PBKDF2-hashed in source, sessions are in memory and clear on restart, and the cookie is HttpOnly + SameSite=Lax but not Secure because this runs over plain HTTP on localhost. A real deployment authenticates against the bank's identity provider.

Định tuyến: lexical so với LLM

Chế độ shadow chạy song song hai bộ phân loại, dùng kết quả của bộ lexical, và ghi lại mọi chỗ hai bên khác nhau. Tỷ lệ trùng khớp một mình không chứng minh bên nào đúng - hai bộ có thể cùng sai - nên các ca lệch được liệt kê đầy đủ để người đọc tự phân xử.

About key handling

            
A key entered here is held in this process's memory only - never
              written to disk, and no endpoint returns it. The catalogue shows a
              mask (sk-a…4f2c), never the value.

            
It is still plaintext in the process environment. Fine for a demo,
              not how to handle credentials in production.
